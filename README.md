# Похела Бойшах — учебный сайт (создано Фарханом)

## Как открыть
Откройте `index.html` двойным щелчком (работает без сервера). Либо: `python3 -m http.server 8000` → http://localhost:8000

## Структура
```
index.html
css/style.css
js/main.js
assets/images/   <- сюда кладите свои фото
```

## Как заменить фото
Положите файл в `assets/images/` с нужным именем (ниже) — страница подхватит его сама.
Если файла нет, сайт показывает красный блок-заглушку с подсказкой, а не чужое фото.
Другое имя? Измените `src="assets/images/..."` в `index.html` (и текст `alt`, если на фото другое содержание).
Совет: ширина 1200–1600 px, JPG, до ~300 КБ.
